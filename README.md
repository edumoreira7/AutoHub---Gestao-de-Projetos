# AutoHub

Sistema de gestão para oficinas mecânicas desenvolvido como projeto acadêmico da disciplina **Gestão de Projetos**.

## Sobre o Projeto

O AutoHub é uma aplicação web voltada para o **uso interno de oficinas mecânicas**, com o objetivo de centralizar e organizar os principais processos operacionais da oficina em um único sistema.

## Funcionalidades

- Cadastro de clientes
- Cadastro de veículos
- Gerenciamento de ordens de serviço
- Controle de serviços realizados
- Controle de peças e estoque
- Geração e acompanhamento de orçamentos
- Histórico de serviços por veículo

## Objetivo

Facilitar a gestão de oficinas mecânicas, reduzindo a desorganização e proporcionando maior controle sobre clientes, veículos, serviços e estoque.

## Público-alvo

- Proprietários de oficinas mecânicas
- Gestores administrativos
- Atendentes e recepcionistas
- Mecânicos

## Tecnologias

As tecnologias serão definidas durante o desenvolvimento do projeto, conforme as necessidades da disciplina.
